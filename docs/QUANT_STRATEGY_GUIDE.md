# 量化策略类型、数据源与参数指南

这份文档用于解释本项目后续可以支持的自动投资算法。它面向正在学习计算金融的软件工程师，重点是把一个策略拆成可观察、可回测、可复现的工程对象，而不是把“量化”理解成一个神秘的黑箱。

## 1. 一个策略由什么组成

建议把每个策略拆成五层：

1. **数据输入**：行情、成交量、基本面、宏观指标、新闻或公司公告。
2. **特征计算**：收益率、移动平均线、RSI、波动率、估值比率、情绪分数等。
3. **信号规则或模型**：根据特征产生买入、卖出、持有或目标仓位。
4. **风险与仓位**：单笔上限、目标波动率、最大回撤、止损、杠杆和现金比例。
5. **执行与评估**：交易费用、滑点、T+N、最小交易单位、成交时间和绩效指标。

策略不一定是训练好的模型。均线交叉和定投是明确公式；配对交易通常需要用历史数据估计关系；机器学习策略才需要保存训练好的模型、特征定义和版本。

## 2. 主要策略类型

| 类型 | 常见例子 | 主要数据 | 可变参数 | 是否需要训练模型 |
| --- | --- | --- | --- | --- |
| 被动规则 / 定投 | 固定金额定投、再平衡 | 价格、交易日历、现金余额 | 金额、频率、再平衡阈值、目标比例 | 否 |
| 趋势跟踪 / 动量 | 均线交叉、突破、时间序列动量 | OHLCV、收益率、可选的波动率 | 快慢窗口、突破窗口、入场阈值、退出规则、仓位规模 | 通常不需要；参数可通过样本外验证选择 |
| 均值回归 | RSI、布林带、短期反转 | OHLCV、收益率、成交量 | 计算窗口、超买/超卖阈值、回归速度、止损线 | 通常不需要；统计回归可需要拟合 |
| 统计套利 / 相对价值 | 配对交易、价差交易、协整 | 多资产价格、成交量、利差 | 配对选择窗口、对冲比率、Z-score 入场/退出阈值、持仓上限 | 常需要统计估计，但不是深度学习 |
| 多因子 / 横截面 | 价值、规模、质量、动量、低波动 | 价格、成交量、财务报表、估值和因子数据 | 因子权重、分组数量、换手频率、行业/个股约束 | 可用线性回归，也可以纯规则排序 |
| 波动率与风险配置 | 目标波动率、风险平价、ATR 仓位 | 收益率、历史波动率、相关性、期权隐含波动率（如有） | 目标波动率、回看窗口、杠杆上限、风险预算 | 常见为公式或统计估计 |
| 组合优化 | 均值-方差、最小方差、Black-Litterman | 预期收益、协方差、基准权重、观点 | 风险厌恶系数、权重上下限、换手成本、再平衡周期 | 不一定；通常需要估计参数 |
| 事件 / 新闻 / 信息驱动 | 财报公告、宏观数据、新闻情绪 | 新闻正文、公告、时间戳、来源、财务数据、价格 | 情绪阈值、事件窗口、来源权重、信号衰减、仓位上限 | 可以是规则、NLP 分类器或大型语言模型 |
| 监督学习 | 收益预测、涨跌分类、风险预测 | 价格、基本面、因子、宏观和事件特征 | 模型类型、特征窗口、正则化、树深、学习率、预测阈值 | 是；必须保存模型与特征版本 |
| 强化学习 / 自适应策略 | 学习目标仓位或交易动作 | 状态、价格、持仓、现金、费用和奖励 | 奖励函数、折扣因子、探索率、动作空间、风险惩罚 | 是；训练和线上推理必须分开 |

### 2.1 本项目现有三个模板的定位

- **均线交叉**：趋势跟踪的入门模板。若 `MA_fast > MA_slow` 可以产生持有或买入信号，反之降低仓位。它需要 OHLCV 中的收盘价，参数是快线窗口、慢线窗口和时间周期。
- **RSI 反转**：均值回归的入门模板。RSI 低于超卖阈值后重新向上可以作为买入触发，超过超买阈值可以作为卖出或减仓触发。参数是 RSI 窗口、超买/超卖阈值和最小交易间隔。
- **定投**：被动规则模板。按交易日历定期投入固定金额，不预测下一根 K 线。参数是每次投入金额、间隔天数、初始目标仓位和现金上限。

这三个模板适合第一阶段，因为它们分别覆盖了“趋势”“反转”和“无预测的资金纪律”，并且可以在不引入训练模型的情况下解释每一次交易。

## 3. 数据源规划

### 3.1 行情与交易数据

- **实时或近实时行情**：本项目当前使用 Futu OpenAPI 保存行情看板报价；它适合实时模拟，但不能替代完整的历史 OHLCV 数据。
- **历史 OHLCV**：历史回测继续只使用 yfinance。需要保存下载时间、请求参数、时区、复权方式和原始数据版本。
- **成交量与盘口**：趋势、流动性和交易成本估计会用到成交量；若将来使用盘口，需要额外保存 bid/ask、盘口深度和时间戳。

### 3.2 基本面与因子

- 美国上市公司的申报文件和 XBRL facts 可以来自 SEC 的 EDGAR API：<https://data.sec.gov/>。
- Fama/French 数据库提供市场、规模、价值、盈利能力、投资和动量等研究因子：<https://mba.tuck.dartmouth.edu/pages/faculty/ken.french/data_library.html>。
- 港股和其他市场的基本面需要确认授权、覆盖范围和历史可追溯性，不能把当前值直接回填到过去日期，否则会产生前视偏差。

### 3.3 宏观、汇率与事件

- 汇率可以先继续使用项目里的固定参考值；更完整的版本可接入 BIS 双边汇率数据：<https://www.bis.org/statistics/dataportal/exr.htm>。
- 公司新闻、公告和宏观事件需要至少保存 `source`、`published_at`、`effective_at`、标题/正文哈希和情绪或事件标签。数据必须以“当时能看到的版本”为准。
- 新闻/AI 策略不应只接收一个当前新闻列表。回测时必须按历史时间点重建信息集，避免把后来发布的内容泄漏到过去。

## 4. 参数和模型应该如何存储

建议每个策略实例都保存以下信息：

```json
{
  "strategy_key": "ma_crossover",
  "strategy_version": "1.0.0",
  "parameters": {
    "fast_period": 10,
    "slow_period": 30,
    "timeframe": "1D"
  },
  "data_requirements": ["ohlcv.close"],
  "model_artifact": null,
  "feature_version": null,
  "risk_rules": {
    "max_position_ratio": 1.0,
    "stop_loss_ratio": null
  }
}
```

对于机器学习策略，`model_artifact` 不应只存一段 Python pickle。至少还要关联：训练数据时间范围、特征列表、标签定义、训练代码版本、模型文件校验值、训练时间、验证区间和样本外结果。生产环境需要模型注册表或对象存储，而不是把大文件直接塞进交易表。

## 5. 推荐的实现路线

1. **策略接口统一化**：输入标准化 OHLCV 和账户状态，输出目标仓位或交易意图；先完善均线、RSI、定投的参数和日志。
2. **技术指标层**：统一计算 SMA、EMA、RSI、Bollinger Bands、ATR、收益率和滚动波动率，避免每个策略重复实现。
3. **风险层独立**：把目标仓位、最大仓位、费用、滑点和 T+N 从信号逻辑中分离，便于比较策略本身与执行规则的影响。
4. **因子层**：加入 Fama/French 或自定义因子，并用时间序列切分做验证。
5. **事件层**：先做公告事件的规则标签，再做情绪模型；每个事件都要可追溯到原始来源。
6. **机器学习层**：最后再引入树模型或神经网络，使用按时间顺序的训练/验证/测试切分，禁止随机打乱未来数据。

## 6. 回测和线上模拟的共同风险

- 前视偏差：使用了当时尚未公开的价格、财报或新闻。
- 幸存者偏差：只保留今天仍然存在的股票，忽略退市标的。
- 复权和公司行动：分红、拆股和合并会影响价格与成交数量。
- 交易成本低估：佣金、平台费、税费、滑点和最小交易单位必须进入撮合。
- 时区错误：美股、港股、期货交易日不一致，本项目账户统一以北京时间 06:00 做结算，但订单成交时间仍应保留原始市场时区和 UTC 时间。
- 过拟合：参数越多不代表策略越好，必须报告样本外收益、最大回撤、波动率、换手率和交易次数。

时间序列模型应使用面向时间的切分方式，而不是普通随机交叉验证。scikit-learn 的 `TimeSeriesSplit` 提供了带时间顺序和可选 gap 的基础实现：<https://scikit-learn.org/stable/modules/generated/sklearn.model_selection.TimeSeriesSplit.html>。

## 7. 参考研究

- 时间序列动量：Moskowitz、Ooi、Pedersen 的研究覆盖股票指数、货币、商品和债券期货，适合作为趋势/动量策略的研究入口：<https://papers.ssrn.com/sol3/papers.cfm?abstract_id=2089463>。
- 配对交易：Gatev、Goetzmann、Rouwenhorst 的相对价值套利研究：<https://www.jstor.org/stable/3844014>。
- 机器学习与资产定价：Gu、Kelly、Xiu 比较了线性模型、树模型和神经网络，并指出动量、流动性和波动率是重要信号来源之一：<https://www.nber.org/papers/w25398>。

以上研究结果适合用于学习和构建可验证的实验，不代表任何收益承诺，也不能替代真实市场中的风险管理和合规审查。
