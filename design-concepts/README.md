# Quant Lab 金融科技视觉方案

这里是独立于现有 React 前端的静态视觉原型，专门用来评估“未登录的我的账户”页面风格。页面不读取后端，也不会改变现有路由。

直接打开 `index.html`，再进入三套方案：

- `01-terminal-flux.html`：深色终端型。强调实时感、数据密度和交易台气质。
- `02-ledger-signal.html`：明亮账本型。强调学习、解释和资金流的可读性。
- `03-circuit-grid.html`：深蓝信号网格型。强调金融科技、系统化策略和多层数据关系。

三套页面使用同一组静态示例数据：模拟账户示例、HKD 1,000,000 初始本金、三个投资项目和未分配现金。差异只在视觉语言和内容编排，方便比较而不会混淆业务能力。
